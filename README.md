# Dynamic Image Gallery

This project is a simple Dynamic Image Gallery built using HTML and CSS. The gallery displays multiple images arranged in vertical columns using Flexbox, creating an attractive and organized photo layout. It is a beginner-friendly project for learning image placement and layout design techniques.

## Features

* Dynamic image gallery layout
* Multiple image columns
* CSS Flexbox implementation
* Simple and clean design
* Easy to customize with your own images

## Technologies Used

* HTML
* CSS
* CSS Flexbox



## How to Run

1. Download or clone the repository.
2. Make sure all image files are placed in the project folder.
3. Open `index.html` in any web browser.

## Gallery Layout

The webpage contains:

* A centered gallery title
* Multiple image columns
* Images displayed vertically within each column
* Flexbox-based arrangement for better organization
